# Toni's Records — Website-Relaunch

Dieses Repository enthält das Relaunch-Konzept für `www.tonis-records.de`.

- **[Konzeptdokument](docs/tonis-records-relaunch/konzept.md)** — Designkonzept, Sitemap, Startseiten-Vorschlag, Farben/Typografie/Bildsprache, Modernisierungsvorschläge pro Bestandselement, Begründung für zu erhaltende Elemente, technische Anforderungen.
- **[Design-Canvas (Moodboard & Wireframes)](https://claude.ai/code/artifact/24f93222-762e-4c92-bf75-e86bca2fd7db)** — Farbpalette, Typografie, Bildsprache und Logo-Interpretation sowie Wireframes der Startseite für Desktop und Mobile.
- `design-canvas/` — Quelldateien des Design-Canvas (Moodboard, Desktop- und Mobile-Wireframe).

**Leitmotiv:** *„Bewahre die Seele von Toni's Records. Modernisiere das Erscheinungsbild."*
