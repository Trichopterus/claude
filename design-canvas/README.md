# Design-Canvas — Quelldateien

Diese `.dc.html`-Dateien sind die Quelle für das veröffentlichte Design-Canvas
(Moodboard, Desktop- und Mobile-Wireframe der Startseite). Der ~2,5 MB große,
vorkompilierte Editor-Payload wird bewusst nicht versioniert — nur diese
Quelldateien sind zum Weiterbearbeiten relevant.

- `Moodboard.dc.html` — Farbpalette, Typografie, Bildsprache, Logo-Interpretation
- `Main.dc.html` — Startseite Desktop (1440px)
- `Mobile.dc.html` — Startseite Mobile (390px)
- `canvas.json` — Anordnung der Artboards auf dem Canvas

Veröffentlichte Ansicht: siehe [Konzeptdokument](../docs/tonis-records-relaunch/konzept.md).
